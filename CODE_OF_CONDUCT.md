# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, keep discussion about the work, and don't harass
anyone, in issues, pull requests, reviews or any other project space.

If someone's behaviour is a problem, contact the maintainer (Grandmask20) through GitHub. Reports are handled
privately, and the maintainer may remove comments, close discussions or block people who don't follow these rules.
