1"""The detector for atlas screenshots. 

2 

3Stages, each scored against atlas_test_data/truth/truth.json (not shipped) with atlas_truth.score: 

4 1. HUD the game's interface (hud_mask_full.png, drawn by the user) is never a map, badge or landmark 

5 2. maps bright-blob candidates -> learned classifier: map (towers included) / not a map 

6 3. badges gold-ring + average-badge spots -> badge classifier -> name from the badge pictures 

7 (badge_refs table + the labelled ones kept in the model); rows of up to 5 badges sit 24 px 

8 above their map, centred on it (user) -> a badge row with no map found = a hidden map 

9 4. landmarks Towers (classifier on found maps: the spire above them); Deadly Map Boss rows -> City (barrel 

10 / blue or red beam) / Hall (beam on a structure beside it) / deadly boss map; Breach 

11 strongholds (old purple rule), locked when a hand badge is near or no map is inside 

12 5. paths amber / dim-gold / fog-orange dash mask -> dash-by-dash tracing between maps by the user's 

13 path rules; two dead ends meeting = a missed map; dashes around a spot are map evidence too 

14 6. biome ground type per map 

15Modes: TRAINING fits models from the hand-labelled truth and stores them in the reference DB 

16(table detector_models); LIVE only reads them and never writes the DB. 

17 

18 python -m grand_project.detect score every stage tested leave-one-screenshot-out (each labelled 

19 screenshot judged by models trained without it) 

20 python -m grand_project.detect train training mode: fit every model on all labelled screenshots -> DB 

21 python -m grand_project.detect train_cities only the City barrel model 

22 python -m grand_project.detect run IMG... live mode: maps per screenshot (reads the DB, never writes it) 

23"""
